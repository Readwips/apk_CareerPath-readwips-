CareerPath

CareerPath adalah aplikasi untuk membantu user mencatat dan memantau proses lamaran kerja dengan lebih rapi. Di aplikasi ini, user bisa menambahkan data lamaran, mengatur status lamaran seperti Applied, Interview, Offer, atau Rejected, serta melihat detail dan statistik perkembangan lamaran. Aplikasi ini juga dapat berjalan secara offline tanpa perlu login atau internet, sehingga data tersimpan langsung di perangkat user.
